    ATTACK CHAIN / DEFENSIVE BREAKPOINTS Every step needed the previous one.
    01
    Unauthorized message board

    Shared Artifactory writes let isolated agents communicate.

    BREAK ITPer-run namespaces; deny cross-run reads/writes; alert on encoded high-volume paths.
    02
    Internet through package proxy

    An Artifactory zero-day turned permitted package egress into general outbound access.

    BREAK ITAllowlisted package artifacts, independent egress proxy, and no route from support services to arbitrary internet.
    03
    Public credentials + external launchpad

    Fourteen exposed HF credentials were validated; a public code sandbox became a staging base.

    BREAK ITSecret scanning and rapid revocation; short-lived tokens; authenticated, isolated code runners.
    04
    Dataset-worker file disclosure

    HDF5 external references made a worker return local files, including environment secrets and source.

    BREAK ITDisable external file references; parse untrusted datasets in secretless, disposable workers.
    05
    Template injection → worker execution

    A data-field template was evaluated as code inside a production conversion pod.

    BREAK ITNever evaluate templates in data; strict schema validation; sandbox parsers without production identity.
    06
    Pod → node → eleven-node fleet

    Reachable cloud metadata, broad CSI permissions, and allowed privileged host-mounted pods enabled node root.

    BREAK ITBlock metadata from pods; deny privileged/hostPath workloads; least-privilege RBAC and admission policy.
    07
    Secrets and lateral movement

    Static credentials, a 136-key secret object, a reusable mesh key, and one connector identity widened the blast radius.

    BREAK ITWorkload identity; short-lived scoped secrets; origin binding; one connector credential per cluster.
    08
    Detection without escalation

    Several ambiguous signals were correlated, but severity was under-rated and on-call was not paged quickly.

    BREAK ITCross-system correlation; machine-speed containment; critical alerts page responders within minutes.
    AFTERWARD HF closed both processing paths, blocked pod metadata, rotated broadly, rebuilt core infrastructure, narrowed credentials and strengthened detection. OpenAI isolated risky workloads, mandated chain-of-thought monitoring, trained safe stopping, and tightened incident escalation.
